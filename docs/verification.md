# Проверка проекта «Соседи»

Дата: 30 октября 2026 года. Windows, Node.js 24.22.1, Next.js 16.4.3, Prisma 6.19.0, PostgreSQL 18.6.

## Выполнено

- Production-сборка Next.js с webpack проходит. Главная и кабинет используют серверный рендеринг; данные сохраняются в PostgreSQL.
- TypeScript `tsc --noEmit` проходит.
- 26 тестов в 6 файлах: правила расписания и пароли; регистрация/подтверждение и роли; параллельные записи, лимит трёх машинок и смежные интервалы; автоматическое истечение; конкурентное принятие заявки; приватность жалоб и файлов; проверка изображений; изоляция демопространств; очистка 205 файлов; восстановление уведомлений.
- HTTP smoke на настоящем production-сервере: публичная страница, запрет анонимного доступа к данным, Origin/CSRF, демосессии, разграничение ролей, создание/принятие/выполнение заявки, уведомления и выход.
- В браузере вручную: демовход жильца; создание брони и отображение в расписании; создание заявки; переключение на мастера в том же пространстве, принятие и выполнение; подтверждение тестового жильца администратором и назначение ему специальности.
- Адаптивные скриншоты главной: 1440, 768, 390 пикселей. Inspector: 0 FAIL, 1 WARN о крупном заголовке публичной главной. Это публичная презентационная страница, не рабочий кабинет; крупный заголовок здесь намеренный. Предупреждения о мелком тексте устранены увеличением основного текста.
- Мобильный кабинет просмотрен при 390 × 844. Таблица управления жильцами имеет собственную горизонтальную прокрутку. Расписание также прокручивается внутри своего блока. Скрытая мобильная навигация исключена из фокуса через `inert`.
- Шрифт Manrope хранится локально, лицензия включена. Изображение здания — авторская SVG-иллюстрация, не фотография реального здания.
- `run-local.ps1` запущен: web и worker стартуют в скрытых процессах, журналы пишутся в `.local`. Повторный запуск не захватывает занятый порт 3000. Самостоятельный PostgreSQL-кластер находится в `.local/postgres`, слушает только 127.0.0.1:55439; существующие базы пользователя не изменялись.

## Независимое ревью

Найденные ошибки сначала воспроизведены четырьмя падающими тестами, затем исправлены; полный набор из 26 тестов проходит:

1. Синтетические публичные профили больше не доступны по известному тестовому паролю.
2. При очистке демопространств удаляются все фотографии до каскадного удаления записей. Сбой удаления файла не скрывается.
3. Истечение брони из HTTP-сценария создаёт то же уведомление, что и worker.
4. Пропущенное напоминание восстанавливается в десятиминутном окне начала сеанса.

## Визуальная оценка

Направление: Editorial greeting с тёплыми зелёными поверхностями, Manrope для кириллицы и отдельной иллюстрацией здания. Manrope выбран вместо Instrument Sans, чтобы обеспечить единый шрифт для русского интерфейса. Главная объясняет сервис, рабочий кабинет ставит текущую задачу первой; особый элемент — пять строк расписания машинок.

Оценка рабочих экранов: визуальная иерархия 8/10, читаемость 8/10, предметность 8/10, адаптация 8/10. Это авторская оценка по скриншотам, не результат пользовательского исследования. Второстепенные метаданные компактны; длинные таблицы и расписание требуют горизонтальной прокрутки на телефоне. Реальные фотографии общежития можно добавить позже вместо иллюстрации.

## Пределы проверки

- Docker Compose и Linux-образ подготовлены, но не запускались: Docker отсутствует в PATH. Нельзя считать контейнерный запуск проверенным.
- Нет публичного размещения и внешнего домена. Проверен локальный production-сервер. Для хостинга нужны Node.js, PostgreSQL, постоянное хранилище файлов и отдельный worker. Доступный Sites-хостинг не поддерживает прямой TCP PostgreSQL для этого стека.
- Ручные проверки выполнены в локальном браузере. Доставка уведомлений за пределами сайта не предусмотрена. Реальных данных администрации и жильцов нет.
